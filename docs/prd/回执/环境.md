本轮在 macOS arm64 执行 go test -race -count=1 -cover ./internal/config ./internal/detector，通过。覆盖率为 config 81.1%、detector 67.2%。Windows amd64 和 arm64 的两个包均通过 go vet，并成功交叉编译测试二进制。

在原生 Windows runner 运行 go test ./internal/config ./internal/detector 会创建临时安装路径及模拟可执行文件。TestWindowsAutodetect 覆盖自动和手动探测、缺失安装和未签名文件；TestWindowsProcessSnapshot 启动测试程序的临时副本以验证系统进程枚举；TestWindowsOrphanLanguageServer 验证残留语言服务和路径归属；TestWindowsRoamingConfig 只写临时 APPDATA。模拟进程读到标准输入关闭后自行退出。

真实 windows-latest 首轮已通过 TestWindowsAutodetect、TestWindowsProcessSnapshot、TestWindowsOrphanLanguageServer。TestConcurrentDictionarySaves 在多个并行重命名上返回 Access is denied。修复后所有 Store 实例共用读写锁，覆盖打开、读取、路径检查和替换。Windows 遇到访问拒绝、共享或锁定冲突时最多重试 6 次，累计等待 560 毫秒，每次仍用同目录重命名。超出预算则保留原文件并返回错误。

原有并发用例保持不变，新增 TestWindowsSaveWithReader 模拟独立文件句柄短暂拒绝删除共享。本地 macOS 配置竞态全套及并发写入重复 20 次通过，修复版 Windows amd64 静态检查和测试交叉编译通过。提交 82dc2a2 在 Windows 原生复跑通过，已核对并发保存、独立读句柄、路径探测和进程测试的 PASS 行。[Windows 作业](https://github.com/chiefcapitalhu/antigravity-zh-gui/actions/runs/45050532005/job/137294425094)。未用发行商签发的 Windows 安装做验签。
