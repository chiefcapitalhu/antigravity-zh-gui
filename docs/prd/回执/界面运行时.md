# 阶段 3 界面运行时

接口基线为提交 `418583c` 后的阶段 3 合同。实现位于 `runtime/ui_translator.js`。宿主确认当前页面为可信 Hub 顶层后，调用固定工厂并传入偏好与词典数据。安装返回语言查询、切换与卸载方法。

| 验收项 | 实现与证据 |
|---|---|
| 可逆文本和属性 | 分别用 WeakMap 保存原始文本、原始属性及最后一次展示值。宿主重用节点时，即便写入值与上一次译文相同，也作为新来源。切回英文、移入保护区和卸载均有回归。 |
| 界面与用户内容 | 只翻译已识别的固定控件。模型名称、插件自定义内容、聊天、思考、编辑、代码、Diff、终端、访客 iframe 及路径与 URL 受保护。输入框只对已核实的 Sidecar 名称控件处理两种固定属性。 |
| 键盘与语言偏好 | 开启后精确消费本平台 Cmd/Ctrl + Shift + L，长按仅切换一次。禁用时保留宿主按键。采用来源隔离的 localStorage，并同步同源其他窗口的真实语言存储事件。 |
| 原创词典接口 | 使用自定义、精确、固定作用域和内置模板四层匹配。外部数据只能提供文案。侧栏品牌仅在已确认的相邻纯文本节点隐藏。 |
| 动态文档 | MutationObserver 合批跟踪更改。已翻译子树移动时重新标记弱引用祖先，便于恢复；首次扫描无需深入受保护的长对话。slot 分配和跨 Shadow 宿主的隔离均纳入回归。 |
| Shadow DOM | 拦截当前世界的 attachShadow，并用弱引用游标分批查找其他世界新增的可访问开放根。每批最多检查 256 个元素，达到时间预算即让出。同一工厂重复安装可通过弱引用找到此前记录的闭合根。已识别的闭合 host 下，光树子节点保持原文，避免翻译投影到受保护区域的文字。其他世界创建或安装前已有且无法取得的闭合根，其内部内容和投影位置无法核验。 |

验证时未启动或改写真实客户端。Node 语法及运行时安全规则检查通过。浏览器验收工人在临时配置的原生 Chrome 中确认 15 组 DOM 用例通过，覆盖重用/重复安装、内容迁移、输入与品牌、平台组合键、动态 Shadow、闭合根投影保护与存储同步。真实客户端内的快捷键处理先后顺序与最终词典覆盖率留待后续阶段验证。
