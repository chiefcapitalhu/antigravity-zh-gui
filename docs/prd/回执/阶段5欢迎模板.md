# 欢迎页标题来源核验

Antigravity 2.34.0 的 Hub 在欢迎页标题元素中使用模板 `Welcome to ${a}!`。在语言服务内嵌 ZIP 的 `main.js` 中，起始反引号位于 UTF-8 字节偏移 9097635，完整模板出现一次，成员 SHA-256 为 `d52ce739c15044c02a32e1b9df62bfe39dd8164c70a2ab783540e6ed5e070251`。

`extract --verify locales/zh-CN` 从起始反引号读取完整模板，按源码拼写核验占位符。该证据限定于 `hub:main.js`、`core.scoped` 和 `onboarding` 作用域。扫描过程仅检查字节。Go 1.22.12 的提取器回归涵盖自动候选排除、其他插值、改变前后缀、正则及注释、普通引号内的副本、错误偏移、局部原文和错误作用域。

以只读方式对本机安装运行提取及五模块回放，默认自动扫描得到 2,815 个位置；合并审核词条后得到 2,899 个位置，299 个审核位置全部通过。自动候选里没有此模板。合并清单中唯一对应行是 `hub:main.js` 的偏移 9097635。合并清单 SHA-256 为 `4a69a4aa10f3e88b2083845a07d146d927b94c73d76a59212388380e641c1133`。
