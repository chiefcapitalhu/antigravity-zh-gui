# 阶段 4 原生词典与加载器回执

本机 Antigravity 2.34.0 的原生模块收录 72 条原创翻译。43 条用于右键菜单，26 条用于应用菜单、更新、退出与 Windows 启动提示，Dock 和托盘各 1 条，另有 1 条托盘助手计数模板。各条目的英文、原始成员名、UTF-8 起始引号字节偏移与成员 SHA-256 均见 `locales/zh-CN/menus_dialogs.json`。

| 来源成员 | 审核的位置数 |
|---|---:|
| hub:main.js | 43 |
| asar:dist/main.js | 13 |
| asar:dist/menu.js | 10 |
| asar:dist/updater.js | 6 |

**来源核验。** 在官方安装上运行只读 `extract --verify`，五模块共回放 295 处独立原文。单独对比候选清单，原生模块有 57 处由自动扫描命中，补充的 15 处来自人工检查的字符串枚举、菜单标题、按钮列表等位置，全部经提取器核对源成员摘要、位置和字面值。验证结果写入临时目录。

**展示核验。** Node 隔离宿主用实际菜单 ID、构造点、弹窗字段与托盘计数形态，逐一验证 72 条的译文能够由展示工厂返回。切换回英文时保留原文。更新动作按原英文状态分派，右键菜单的动作 ID 和返回值保持原语义。动态错误正文、发行版名称和 Electron 系统自动生成的菜单标题保留客户端显示。托盘的打开命令由运行时拼入应用名，基础词典未收录完整固定英文。真实客户端里的菜单重建依赖宿主接线，本次测试使用隔离宿主。

**产品接口。** `locales.Load(custom)` 为每次调用提供独立词典。`locales.Build(platform, prefs, custom)` 生成渲染进程和原生展示工厂。`locales.ValidateCatalogBytes` 供提取器校验同一份内存快照，覆盖源格式、重复 JSON 字段、匹配键冲突、泛用短词、专有词、作用域及全局词遮蔽局部译文。

**已执行。** `go test -count=1 -cover ./locales ./runtime ./internal/extractor`、`go vet ./locales` 通过，加载器语句覆盖率为 89.1%。`node --test tests/native.test.cjs tests/runtime-policy.test.cjs` 通过 6 项。Go 还分别打包了 darwin 和 windows 的工厂，并在 Node 中执行了含个人词条的实际嵌入工件。Windows 分支的来源为官方 macOS 分发包中包含的共享代码。
