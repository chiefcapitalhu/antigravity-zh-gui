# 阶段 5 本地控制台

无参数入口启动在系统分配端口上的 IPv4 回环监听器。浏览器进入带一次运行专用令牌的地址后，页面把令牌从地址栏清除，并在本标签页保存，以支持刷新。浏览器启动失败时，启动终端会给出手动打开的本机地址。

页面可探测或手动选择安装、查看签名和运行状态，设置界面语言、热键、品牌及 macOS 整包备份，执行汉化、英文还原、整包还原或完整性验证。项目中的 HTML、CSS 和 JavaScript 都嵌入二进制。操作日志显示自开始以来的累计时间及每一步的毫秒耗时。审计区显示报告中的归档路径、大小和前后 SHA-256。个人词条在本地保存，下次汉化时编入客户端。

## 验收

| 项目 | 已执行检查 |
|---|---|
| 本机访问控制 | 所有 API 都是 JSON POST。每个接口在服务端检查精确 Host、Origin 和 32 字节随机令牌对应的请求头。单测检查了缺失及重复凭据、错误端口、未知主机、不同来源、预检、类型、超限和多余请求体，敏感响应禁止缓存 |
| 操作顺序 | 模拟任务执行期间可以读取增量进度和最终审计。竞争启动、配置更改、词条写入和退出都被拒绝。在服务上下文结束时，服务器等正在执行的事务完成 |
| 浏览器 | 运行 `node tests/panel.cjs`，在两个临时 Chrome 配置上加载实际静态资源和内存模拟服务。检查桌面双栏、窄屏单栏、设置、运行中按钮保护、个人词条显示与删除、逐步用时、审计、还原跳过理由和退出 |
| Go | 在本机 Go 1.22.12 下执行 `go test -count=1 -cover ./internal/server`、`go test -race -count=1 ./internal/server` 和 `go vet ./internal/server` |

这些单元与浏览器用例使用模拟数据。客户端副本的真实文件操作由编排另行验收。
