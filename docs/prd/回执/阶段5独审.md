# 阶段 5 独立复核

复核对象是正式 CLI、共用操作服务、嵌入式控制台、宿主语言同步和 ASAR 验证还原路径。所有写入复验均使用临时夹具。开发机上的官方 macOS 安装仅供静态读取。

| 复核项目 | 证据 |
|---|---|
| Windows 部分平台锚点可用时，更新语言选项 | 临时 Windows 安装只提供已识别的原生弹窗锚点。使用自定义词条连续应用中文、英文、中文，每轮核对实际写入的原生文案与警告。最后还原，整个 ASAR 与初始文件逐字节相同。审查发现的英文默认语言重复应用失败已修复。 |
| 控制台还原结果 | 曾在签名检查导致跳过时显示还原成功。直接执行正式页面的结果展示函数，分别验证有警告的跳过、无须还原、实际写入完成三种回执，页面给出各自对应的结果并展示跳过原因。 |
| 宿主热切换 | 独立夹具执行正式预载脚本，完成已识别本机主窗口初始化和模式事件传递，并覆盖其他端口、远程窗口、来源不符及子帧，共五种场景。 |
| 多个控制台同时编辑个人词典 | 修复前，八个进程分别添加 14 个不同词条，共收到 112 次成功响应，磁盘最终只有 17 条。修复将词条的读取、编辑与保存放到同一把跨进程锁内。原夹具复验通过，加上逐项核对英文和译文的断言后再跑三轮，每轮 112 条全部正确落盘。 |
| 配置故障后的再次编辑 | 在临时词典中分别制造合并后超过 2 MiB、已有 JSON 损坏两种情况。正式请求处理器均返回错误并保留文件原始字节。超限后可立即保存较短词条，损坏文件在夹具中修复后也能继续保存。三轮复验通过。 |
| 服务与事务 | 使用 Go 1.22.12 离线执行 `go test -count=1 ./...` 和 `go vet ./...` 通过。测试覆盖精确 Host、Origin 和 token 校验、任务并发、运行中的客户端保护、篡改、签名失败回滚、还原和 CLI 合成安装流程。六项 Node 原生文案和运行时策略测试通过。 |

本机 Hub 的语言偏好按浏览器来源保存。客户端重启并改用其他端口时会采用补丁默认语言，此行为已在 README 中注明。Windows 官方安装副本和真实平台菜单显示未在本复核中实测。真实 macOS 副本验收和 GitHub Actions 运行号由阶段总验收记录提供。

多进程复验在 macOS 运行。每个子进程使用正式控制台请求处理器、服务和配置存储，以内存 HTTP 请求访问同一临时词典。仓库的 `TestDictionaryAcrossProcesses` 也已在本机通过，覆盖持锁进程意外退出后的继续读写。
