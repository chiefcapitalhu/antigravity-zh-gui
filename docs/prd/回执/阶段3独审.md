# 阶段 3 独立复核

以阶段 3 的接口约定为基线。复核使用生产 JS、临时 Chrome 配置和本地合成页面，检查已知 UI、保护区、原生菜单动作、词典数据及测试执行边界。

| 项目 | 独立复现 | 验收条件 |
|---|---|---|
| 闭合根的插槽隔离 | 同一 JS 环境内新建闭合根，在终端节点中放置 slot。已识别按钮作为宿主的 light DOM 子节点，在受保护的终端中显示。浏览器将它的 assignedSlot 返回为空。初版把 Save 改成了中文。 | 终端内显示的文字和属性保持原值，并且动态插槽变化能撤销已翻译的值 |
| 闭合根的重装 | 首次装载后创建闭合根，其中独立的合法按钮显示中文。用同一工厂在同一窗口重新装载，初版只能恢复原文，第二个实例无法找到该根。 | 工厂重装后仍能翻译其已捕获的合法控件，英文模式能复原 |

两项均已修复并用同一临时 Chrome 页面独立复验。修复前，终端插槽、闭合根内合法按钮、重装后的合法按钮依次显示“保存”“保存”“Save”。修复后，三处依次显示“Save”“保存”“保存”。该测试中的 assignedSlot 始终为空。

可观察边界取决于宿主。对于同一执行环境内捕获的闭合根，运行时以弱引用关系跨重装保留入口，并保守保护其宿主的 light DOM。对于装载前已有或其他隔离环境创建的闭合根，浏览器不会提供内部树及插槽关系。这类根内部的控件和外部节点投影后的精确归属仍无法核实。

原生菜单与脚本约束的五个 Node 用例在本机复核通过。原生菜单的展示适配保持右键回调的原始接收者、选择 ID 和返回值，更新动作使用英文状态分派。Go 生成的工厂对窗口身份和来源设有限制。正式词典及 Electron 副本接线分别属于后续阶段。
