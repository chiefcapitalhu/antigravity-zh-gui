# 阶段 2 · ASAR

接口基线为本地提交 `9321c4f`。实现位于 `internal/asar/`，本轮集成提交由编排登记。

已交付独立的 Pickle / JSON 文件树解析、原始 header 摘要、按成员读取、按已有成员重打包和白名单审计。报告按路径排序，给出改动前后大小与 SHA-256。不传替换时完整复制原始归档。传入替换时保持普通成员之间的间隙以及文件末尾的原始字节，重算变长成员后的偏移。

归档链接与 unpacked 成员在审计中核对完整描述；成员内容读取和重写限于普通打包文件。调用方应把目标路径选在自己独占的临时目录，候选文件须事先不存在。解析限制为 64 MiB header、256 层 JSON 嵌套和 100 万个值；读取单成员到内存的便利接口限 256 MiB。归档复制、未改成员比对和内容摘要均通过流式 I/O 完成。

本地使用 Go 1.26.11 darwin/arm64，在关闭模块网络访问的环境中执行。
