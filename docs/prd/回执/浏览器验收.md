# 阶段 3 浏览器验收

入口为 `node tests/browser.cjs`。运行器使用本机 Chrome、临时用户配置和临时 HTML/JS。页面通过 file 协议打开，内容安全策略禁止连接；无本地服务器、调试端口、外部字体或 npm 包。测试结束后清除该轮临时目录。可用 CHROME_BIN 指定 Chromium 可执行文件。

测试以可辨识的 Hub 控件构造合成页面。运行器读取最终 DOM 中的结构化结果；页面未加载、未执行断言、未报告完成或任何断言失败均返回错误。

| 范围 | 验收内容 |
|---|---|
| 词典与无损恢复 | 自定义、整句、作用域及时间模板的顺序；字面 HTML 样式文本；连续切换后的节点身份、空白和三类展示属性 |
| 编辑与私有内容 | 受保护区内测试 ID 即便命中也跳过；保留编辑器、终端、聊天、思考、Diff、文件路径、URL、用户模型名及 iframe 内容 |
| 动态更新 | 宿主重写和删除属性、同值重写、断开与重连、控件移入消息或终端区域、slot 的组合树变更 |
| Sidecar 输入框 | 固定占位及无障碍名称、宿主更新、用户输入、默认内容、焦点和双向选择状态 |
| Shadow DOM | 安装前、安装后、嵌套 open root 与受保护宿主；模拟另一 JS 世界保有原始 attachShadow 方法时的后挂 open root |
| 热切换 | Windows 和 macOS 精确组合键、长按、输入法、禁用后的宿主事件、提示出现与消失、语言偏好、右键菜单同步、重复安装与卸载 |

CI 在 windows-latest 和 macos-latest 运行同一夹具，并单独执行 `node --test tests/native.test.cjs tests/runtime-policy.test.cjs`。策略检查扫描打包的两个生产脚本，覆盖动态执行、HTML 写入、网络 API 和字符串计时器。Electron 的跨世界闭合 ShadowRoot、实际快捷键与官方客户端副本留待后续集成验收。

本机 macOS Chrome 执行 13 组 DOM 回归全部通过，两个生产脚本的策略检查均通过。验收曾发现已翻译按钮经 slot 投影到终端后没有恢复英文；修复后重跑通过。模式同步由同源 iframe 改写 localStorage 产生真实浏览器事件，另核对页面构造的事件无效。本轮也验证在同一 JS 任务中将已译按钮移动至新消息容器，以及随后将普通父容器改变为终端时的恢复。
