# 阶段 4 只读词条提取与回放

本机 Antigravity 2.34.0 提供了八个固定资源。七个来自 ASAR，包括 `dist/main.js`、`dist/menu.js`、`dist/tray.js`、`dist/updater.js`、`dist/ipcHandlers.js`、`dist/provisionSplash.js` 和 `dist/ideInstall/wizardHtml.js`。Hub 的 `main.js` 来自语言服务程序内同时含有 `index.html` 的 ZIP。提取器根据 ZIP 中央目录定位该成员，在内存中限量解压，并按原始成员字节计算 SHA-256。

以下命令可在仓库根目录执行。输出目录的上一级须存在。每次选择一个新目录，避免覆盖先前的审核材料。

```sh
go run ./cmd/antigravity-zh-gui extract --target /Applications/Antigravity.app --out ./candidate-report
go run ./cmd/antigravity-zh-gui extract --target /Applications/Antigravity.app --verify ./locales/zh-CN --out ./reviewed-report
```

自动候选来自展示字段和 React 静态子文本，需人工审核上下文。第二条命令还会核对五个模块的完整结构、安装版本、成员摘要和每条证据。位置从成员首字节算起，必须指向静态 JS 字符串的开引号。原文须与该完整字符串解码结果一致。导出的 `candidates.json` 保留所有候选位置，以及审核补入的位置。新版本可通过 `--diff <旧版 candidates.json>` 比较同样选项下的结果。输出的 `diff.json` 按成员与原文识别新增、消失，位置平移不会产生变化。

| 2.34.0 本次验收 | 结果 |
|---|---|
| 默认离线扫描 | 8 个成员，2,815 个候选位置 |
| 五模块证据回放 | 295 条逐项通过，分布在 295 个独立位置 |
| 合并后重复运行 | 2,897 个位置，增加 0、删除 0，清单 SHA-256 为 `fc3548feba2f519249c9f6fee04633adeb824aea4a53dba1864a4b55adfd6014` |
| 本地 Go 检查 | `go test -race -count=1 -cover ./internal/extractor ./cmd/antigravity-zh-gui` 通过，语句覆盖率分别为 80.4%、53.8%。Windows amd64 目标的 `go vet` 通过 |

独立复核发现函数声明后紧随的正则可能被误读。修正后，`function closePopup() {} /"Close"/.test(text)` 中的引号不产生词条；`const n = function ratio() {} / '4' / 2` 中的字符串仍可按偏移核验。八组回归样例涵盖普通函数、异步生成器、类、箭头函数与对象。修正后重新只读提取，五模块全部通过，合并清单 SHA-256 与上表相同。

测试在临时目录构造两平台资源，覆盖带前后缀的 ZIP、跨块目录标识、伪造或重复成员、注释和正则中的引号、转义和模板、错误位置与摘要、词典结构错误、Diff 与输出保护。真实客户端验收仅访问静态文件。`--live --live-origin http://127.0.0.1:<端口>` 属于可选开发操作，仅读取指定本机服务的静态 `/main.js`。本轮未向真实服务发起请求。候选数代表扫描所得的字节位置，不衡量界面展示覆盖率。
