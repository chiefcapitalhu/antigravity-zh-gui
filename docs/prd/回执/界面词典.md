设置面板反复使用同一标题组件。文件权限页同时核对文件读取和写入两行的固定说明，网络权限页核对读取网址的固定说明，终端命令行则用于识别工具权限和本地权限区域。模型配额标题目前只在同卡片显示 `No quota information available.` 时翻译。这些条件变化后，运行时会复核并恢复失去身份依据的文本。合成 DOM 已检查固定说明与标题同步切换、去掉证据后恢复原文，以及自定义模型组与内置标题同名时的行为。

模型选择、添加模型和 MCP 修复提示使用共享弹层。运行时核对宿主登记的唯一描述关系、控件身份、原文及弹层内的位置。弹层重新分配给另一项、多个控件同时声称同一弹层或控件移入对话正文时，会重新判断。设置侧栏采用固定分组和已知按钮双重限定，避免用户把工作目录取名为 Agents 时改到该名称。生成文档标题和文件预览说明均与相邻评论正文、文件名分开处理。图标字体使用的原始字形名以及包含个人 MCP 服务名称的动态无障碍标签保持原文。

## 已知缺口与验证
