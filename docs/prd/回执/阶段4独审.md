# 阶段 4 独立复核

复核样本为本机 macOS Antigravity 2.34.0。使用独立脚本按 ASAR 头和内嵌 ZIP 读取原始成员，逐份比对 SHA-256，再按词典给出的字节位置检查完整英文及其转义。五模块共 295 条，分布在 295 个不同位置。核心、工作目录、设置、助手与原生菜单分别占 40、48、63、72 和 72 条。生产提取命令以同一安装目录运行，回放 295 处，合并自动候选后输出 2,897 处。

| 复核中退回的问题 | 修复后的独立检查 |
|---|---|
| 静态词法扫描曾把函数声明后正则表达式中的引号内容收为字符串 | 将生产扫描器拷至临时测试模块。相同输入先前得到两个候选字面值，修复后只得到真正的界面字符串。仓库另有声明、表达式和除法等配对回归 |
| 正式控件可包含图标字体。图标组件回退时把字形名存入文本节点 | 临时无头 Chrome 加载生产运行时，用个人词条命中字体字形名。按钮的无障碍标签译为中文，图标仍显示原字形。切回英文再切中文均通过 |
| 部分 MCP 按钮的无障碍标签包含用户的服务名称。待验实现曾将其整体替换 | 临时 Chrome 使用两个含 Atlas 服务名的个人词条。修复前两个无障碍标签均被覆盖；修复后 Configure 和 Fix with Agent 的固定按钮文案可翻译，两处原无障碍标签在三次模式检查中完整保留 |

复核执行了 18 组仓库浏览器测试与 6 项 Node 测试，并在独立临时页面进行上述模式检查。中文词典覆盖的右键菜单、应用菜单、弹窗及托盘计数在隔离的原生展示工厂中验证。源文件对应关系、模拟界面行为以及实际客户端显示是三项不同的验收结果。客户端副本中的菜单重建、真实平台显示和全界面覆盖留在阶段 5 核验。
