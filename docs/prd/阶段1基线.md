# 本机 macOS 构建基线

只读研究对象为 Antigravity 2.34.0，arm64，包标识 com.google.antigravity。ASAR 的 789 个打包成员均通过文件及分块摘要校验。另有 377 个 unpacked 文件与 148 个子目录。整包通过 codesign 严格验证的条件尚未满足。

ASAR 内 dist/preload.js 对应本机 Hub；dist/menu.js、dist/main.js 与 dist/tray.js 共同负责应用菜单、Dock 与托盘；dist/updater.js 的更新弹窗有两条调用分支，共用一份文案；dist/ipcHandlers.js 构造 Hub 右键菜单。普通加载页只有 SVG。Sidecar 的插件视图和语言服务二进制应保持原样。

主界面静态组件来自 language_server 内嵌的 ZIP。openNewConversation 已占用 Cmd/Ctrl + Shift + L。启用语言快捷键时的优先级、真实 Windows 基线与多窗口行为留待相应阶段验收。
