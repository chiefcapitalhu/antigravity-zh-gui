# 阶段 3 运行时接口与派单

基线为 418583c。本阶段交付可嵌入的固定运行时、原生文案适配器与离线回归。首批正式词典在阶段 4 交付，客户端副本端到端验收在阶段 5 进行。

| 负责方 | 范围 | 验收 |
|---|---|---|
| 界面运行时 | runtime/ui_translator.js | 顶层 Hub 内的已知 UI 控件可译，动态更新、模式切换和卸载可还原，受保护内容完整 |
| 原生文案与打包 | runtime/main_hooks.js、runtime 下的 Go 资源及测试、tests/native.test.cjs | 词典和偏好只作为数据，菜单的动作、角色、ID、用户提供的名称保持原值；固定资源可从 Go 读取 |
| 浏览器验收 | tests 下的真实 DOM 测试与运行器、CI 工作流 | 本机和双平台 CI 从临时浏览器配置运行离线页面，失败有可读断言 |

**界面接口**　ui_translator.js 是一个具名函数表达式，计算该表达式得到 installTranslator(window, options)，不自行在页面全局注册对象。宿主在已确认的 Hub 顶层调用。返回 {getMode(), setMode(mode), dispose()}。options 包含 hotkey、defaultLang、platform（darwin 或 win32）、brand（keep 或 hide）、custom、exact、scoped、templates、onModeChange。custom、exact 是英文到中文的对象。scoped 是 {scope, entries} 数组，scope 为固定枚举，例如 toolbar、model、sidecar。templates 是 {id, format} 数组，id 引用运行时内置安全模板（minutesAgo 等），format 使用 {n}。外部数据不能指定脚本、选择器或正则。

**原生接口**　main_hooks.js 同样为函数表达式。对调用方提供基于模式的菜单、托盘、Sidecar 外壳和原生右键菜单的展示字段翻译。运行在既有菜单构建边界，用稳定标识及英文原文共同匹配。对未知标识、动态文件名与插件名称保留原值。宿主可以从 onModeChange 收到 zh/en，更新展示层。动作与显示文案分别保存。

**Go 接口**　runtime 目录的 l10nruntime.Build 接收平台、config.Preferences 和 Dictionary，返回含固定 HubFactory、NativeFactory 的 Bundle。Hub 宿主提供已核实的顶层窗口身份和精确来源。原生适配器的 wrapShowContextMenu 仅包裹已有的菜单展示调用；刷新菜单时使用原始英文模板。阶段 3 的跨端验收使用合成宿主验证模式通知，真实 Electron 进程之间的接线和整包安装效果须在后续副本中验收。

**测试范围**　使用原创合成输入。代码、聊天、思考、编辑区域、终端、Diff、路径、URL 和访客 iframe 都是保护区。已有和动态 Shadow DOM、节点移动、宿主重用文本和属性、多次安装与卸载都需检查。快捷键开启时占用官方新建对话组合键，关闭时交给宿主。上下文隔离下无法访问的闭合树须记录为平台限制。全程禁止写入真实客户端或用户会话。
