# 阶段 2 接口

模块名 antigravity-zh-gui，Go 1.22，标准库。

* asar.Rewrite(sourcePath, candidatePath string, replacements map[string][]byte) error 在新路径构造归档，只允许替换已存在的普通打包文件。空替换逐字节往返。
* asar.ReadFile(archivePath, member string) ([]byte, error) 与 asar.HeaderHash(archivePath string) (string, error) 用于读取和审计。
* asar.VerifyCandidate(sourcePath, candidatePath string, allowlist map[string]bool) (*asar.AuditReport, error) 校验树、元数据和内容，报告含路径、大小、摘要。
* detector.Inspect(target string) (detector.Installation, error) 自动探测或处理显式路径。Installation 有 Root, Archive, Version, Platform 字符串，Platform 取 darwin 或 windows。
* detector.Running(installation detector.Installation) (bool, error) 检查失败视为不可修改。detector.VerifyOfficial(installation detector.Installation) error 验证 macOS 包签名及发行方。
* 补丁器只面向本工具已审核的本地化资源。事务模块内部测试可用私有依赖替身，生产入口不接受任意目标文件映射、用户脚本或任意命令。具体词典及界面运行时按阶段 3 和 4 单独验收。
* 阶段 1 定位到 macOS 2.34.0。当前安装整包验签失败。Windows 本轮使用 macOS 包中可见的 Windows 分支和临时构造的安装验证。GitHub Actions 的 windows-latest 负责原生执行。
* Windows 白名单只涉及 dist/updater.js 的手动检查结果文案与 dist/main.js 的 WSL 初始化失败弹窗标题。各自独立匹配。任一规则缺失或不唯一时返回含成员名的警告，其他命中项可继续。零命中时须保留原归档、备份和缓存。
* patcher.Apply 的结果分别报告 Committed、Warnings 和文件审计，以便界面呈现全部跳过、部分成功和完整成功。Windows 宿主自身只读。真实产品版本的显示效果仍需副本验收。
