# 阶段 5 交付约定

基线为 `d11ad9d`。本阶段把 2.34.0 的 295 条已审核文案接入补丁、命令行和浏览器控制台，建立单文件构建与客户端副本验收入口。

| 负责方 | 范围 | 验收方式 |
|---|---|---|
| 宿主接线 | `internal/patcher`、固定双语工厂 | 审计每个实际改动的成员。只能在经识别的本机 Hub 和原生文案构造点使用内嵌工厂。核验热键、模式同步、恢复和平台跳过。 |
| 控制台 | `internal/server` 和内嵌页面 | 在浏览器完成体检、设置、词条及操作回放。校验精确地址、令牌、来源、退出和并发状态。 |
| 命令行与服务 | `internal/app`、`cmd/antigravity-zh-gui` | 命令行和网页共用相同服务；无参双击、操作回执和所有子命令均可验收。 |
| 编排与验收 | 启动说明、MIT、CI 和发版构建 | 用最低支持的 Go 版本编译四个目标，核对校验清单，测试新生成的二进制。在允许写入的临时副本验收应用、验证、恢复，各平台单列证据。 |

开发只读取已安装的客户端。进程检测同样保护测试副本。GitHub 手动构建供验收，推送版本标签才创建 Release。
